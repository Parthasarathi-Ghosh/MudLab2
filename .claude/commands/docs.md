Switch to the **documentation track** for MudLab2.

1. Read `docs/DOCUMENTATION-PLAN.md`. It holds the three deliverables, the
   source inventory across both repositories, the rules for each document, and
   a **Where we stopped** section with the next actions.
2. Continue from **Where we stopped**, unless the user names a different piece
   of the track.
3. Verify every UI instruction against the real widgets before writing it —
   menu paths, dialog titles and button labels — rather than recalling them.
   The old GTK app's documentation describes a different UI and must not be
   copied verbatim.
4. Before the session moves off this track, update **Where we stopped** so the
   next session resumes without re-deriving anything.
