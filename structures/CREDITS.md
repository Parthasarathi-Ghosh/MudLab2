# Credits: published crystal structures

Every structure in this folder is published work. Each file is the CIF as
published by the Crystallography Open Database (COD) or the American
Mineralogist Crystal Structure Database (AMCSD), copied byte for byte; only
the file name is new.

**Cite the original article whenever you use a structure.** The article for
each file is listed below. The terms of use are in README.md.

## The databases

- Gražulis, S. et al. (2009). Crystallography Open Database - an open-access
  collection of crystal structures. *Journal of Applied Crystallography* 42,
  726-729.
- Downs, R. T.; Hall-Wallace, M. (2003). The American Mineralogist Crystal
  Structure Database. *American Mineralogist* 88, 247-250.
- 19 of the files were obtained through atomipy (M. Holmboe,
  github.com/mholmboe/atomipy), which bundles the Avogadro 2 crystal library;
  they are COD or AMCSD structures and carry those terms.
