## New in 1.1.0

### 65 published crystal structures ship with MudLab

A new **Structures** folder beside `MudLab.exe` holds 65 published crystal
structures (CIF files) chosen for clay XRD:

- **Clays** — 18 layer silicates: the kaolins, lizardite, talc, pyrophyllite,
  the illites and micas, the smectites, vermiculite and the chlorites.
- **Non-clays** — 47 minerals that occur with clays: sepiolite and
  palygorskite, silica and the feldspars, carbonates, sulfates, sulfides and
  halides, Fe, Ti and Al oxides, zeolites, apatite and zircon.

Every file is the published file, unchanged. **CREDITS.md** gives the citation
for each one: please cite the article whenever you use a structure.
**manifest.csv** lists each structure's formula, citation, database number and
notes.

- **Import CIF…** in the component editor now opens in *Clays*. **Import
  Non-Clay**, **Calibrate FWHM** and **Add structure…** in Edit Mixture →
  **Non-clay…** open in *Non-clays*. Once you pick a file from a folder of your own, each dialog goes
  back there for the rest of the session.
- **Help → Structure Collection…** opens the folder.
- The nacrite, muscovite-2M1 and paragonite-2M1 files describe two layers. Their
  note in manifest.csv says to set *Layers stacked in the published cell* to 2
  in the import review.

### Fixes to reading CIF files

Testing those 65 files found four bugs in how MudLab reads a CIF:

- **Water read as tungsten.** Water oxygens labelled `Wat1`, as in many AMCSD
  files, were read as tungsten when building a non-clay reference pattern, and
  `H2O` labels as hydrogen. Vermiculite's and sepiolite's reference patterns
  were badly wrong. Both labels now read as oxygen.
- **Water and deuterium dropped without a word.** **Import CIF…** left out
  those sites, so an imported vermiculite lost its interlayer water. They are
  kept now; deuterium is read as hydrogen, which X-rays cannot tell apart.
- **Symmetry not read.** Where a file's symmetry list has an ID column, common
  in COD files, **Import CIF…** read the IDs instead of the operations. The
  structure was then taken as P1, with most of its atoms missing. Gypsum,
  jarosite and tridymite now get all their operations.
- **Unsupported elements misread.** An element MudLab does not support was read
  by its first letter: lead as phosphorus, cerium as carbon. Such sites are now
  named in the import review's warning line.

### Also

- **Licences.** The release now includes a `licenses` folder with the licences
  of the software MudLab bundles: Python, Qt and Qt for Python (under the GNU
  LGPL), NumPy, SciPy, Matplotlib and others. Start with
  `licenses\THIRD-PARTY-NOTICES.txt`. `LICENSE` now reproduces the notice of
  PyXRD, which MudLab descends from, as PyXRD publishes it (BSD 2-Clause). It
  also states that the crystal structures in `Structures` keep their own terms.
