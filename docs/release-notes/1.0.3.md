## New in 1.0.3

### The manual is now in the app

Press **F1**, or **Help → Manual**. It ships inside the folder and works
offline. **Help → Manual existed in 1.0.0–1.0.2 but did nothing at all** — the
menu item was there, the F1 shortcut was there, and nothing was connected
behind them.

It opens on a new **walkthrough**: the short path from importing a scan to
saving a result — import, specimen settings, shift/trim/smooth, find peaks,
match minerals, load default phases, build a mixture, optimize, refine, save.
The full reference is one click away.

### A goniometer setup that produced nothing

**D8 ECO Lynxeye XE** shipped with its 2θ range stored as 3° to 3° — a
zero-width range, so applying it calculated an **empty pattern** with no error
to explain why. It is now 2–90°. This bug is inherited from upstream PyXRD and
is still present there and in the original GTK MudLab.

### Imported scans now set the goniometer range

The 2θ range and step count are taken from the scan you import, instead of
being left at the 3–45° / 2500-step default however wide your measurement
actually was. A goniometer setup you apply afterwards still overrides all of
it, as before.

> **A reminder this makes worth repeating:** peak positions depend on the
> **wavelength**, and mineral matching converts your peaks to d-spacings using
> it. Plain-text and Rigaku `.raw` files carry no wavelength, so MudLab assumes
> copper Kα₁. Measured on cobalt and left as copper, quartz is identified as
> *diopside*. Check the Goniometer tab first — the manual says so at the point
> where it matters.

### Reset a phase to its shipped default

A phase can be restored to the default structure it came from, from the phase
list in **Edit Phases**. Its name, colour, inheritance and links are kept; only
the structure returns to the shipped values.

### Also

- **Muscovite** is now offered in the default phase catalog. It was bundled but
  never listed — the same omission the original app had.
- The **emission-spectrum editor** rejects impossible wavelengths. A missing
  leading zero (1.544 for 0.1544 nm) is a valid number and an impossible
  wavelength, and it used to be accepted silently, after which reflections
  simply stopped appearing.
- Fixed a crash when detecting peaks or matching minerals on an empty pattern.
- Charts now use the same typeface as the rest of the interface.
